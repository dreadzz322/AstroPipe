# AstroPipe

Конвейер обработки астрономических снимков, рассчитанный на старые телескопы и плохую
оцифровку: по сырому кадру находит звёзды, определяет точные небесные координаты кадра,
измеряет звёздные величины и ищет движущиеся объекты (астероиды, кометы).

> **Сотрудникам обсерватории:** скачайте `AstroPipe.zip` на странице **Releases** справа и откройте внутри `ИНСТРУКЦИЯ.html` — там всё по шагам, с картинками.

## Быстрый старт (Windows)

1. Установите Python 3.11 или новее с [python.org](https://www.python.org/downloads/), отметив «Add python.exe to PATH».
2. Распакуйте архив в любую папку и запустите `install.bat` — он поставит библиотеки и прогонит проверку
   (нужен интернет, несколько минут).
3. Перетащите снимок или скан на `run.bat`, ответьте на вопросы о координатах и масштабе.
   Результаты появятся в папке `astropipe_out` рядом со снимком.

Для привязки к небу нужен интернет: звёздный каталог Gaia скачивается под каждое поле
(и запоминается, повторно не качается). Всё остальное ниже — для работы из командной строки.

## Что умеет

| Этап | Модуль | Что делает |
|---|---|---|
| Загрузка | `io.py` | FITS и растровые сканы (TIFF/PNG/JPEG, 8 и 16 бит) |
| Калибровка | `calibrate.py` | мастер-bias/dark/flat и их применение |
| Чистка оцифровки | `calibrate.py` | автоопределение негатива, полосы сканера, горячие и мёртвые пиксели |
| Поиск звёзд | `detect.py` | карта фона (виньетирование, засветка), согласованный фильтр, центры до ~0,02 пикс |
| Сопоставление | `match.py` | метод треугольников: любой поворот, масштаб, зеркальное отражение |
| Астрометрия | `astrometry.py` | привязка к Gaia DR3 → WCS; учёт собственных движений звёзд на эпоху снимка |
| Фотометрия | `photometry.py` | апертурная; нуль-пункт для ПЗС или полином для нелинейных пластинок |
| Сложение | `stack.py` | совмещение серии по звёздам и сложение с отсечением выбросов |
| Движущиеся объекты | `moving.py` | цепочки детекций с постоянной скоростью, координаты и скорость в ″/мин |

## Установка

```bash
py -m venv .venv
```

```bash
.venv\Scripts\python -m pip install numpy scipy astropy pillow astroquery pytest
```

`astroquery` нужен только для скачивания каталога Gaia; без интернета можно дать свой
каталог через `--catalog файл.csv` (колонки `ra`, `dec` в градусах и `mag`).

## Быстрая проверка на синтетике

```bash
.venv\Scripts\python -m astropipe simulate demo/data
```

```bash
.venv\Scripts\python -m astropipe process demo/data/scan.png --catalog demo/data/catalog.csv --ra 83.85 --dec 22.03 --out demo/out
```

`scan.png` — имитация плохого скана: 8-битный негатив с полосами и нелинейным откликом.

## Сканы фотопластинок

У скана нет заголовка, поэтому всё нужное задаётся ключами:

```bash
.venv\Scripts\python -m astropipe process пластинка.tif --ra "19 21 00" --dec "+41 10 00" --epoch 1965.5 --focal 3438 --dpi 1200 --out out
```

| Ключ | Откуда взять | Зачем |
|---|---|---|
| `--ra`, `--dec` | журнал наблюдений, конверт пластинки | центр поля; хватает точности в полградуса |
| `--epoch` | дата съёмки (год с долями) | звёзды каталога сдвигаются на своё место в тот год |
| `--focal` + `--dpi` | паспорт телескопа и настройки сканера | масштаб; вместо них можно `--plate-scale` (″/мм) или `--scale` (″/пикс) |
| `--bin N` | — | уменьшить огромный скан в N раз |

Что конвейер делает для пластинок сам:

- распознаёт негатив и инвертирует его;
- учитывает дисторсию оптики и неравный масштаб сканера по осям (полином SIP 3-й степени; `--sip 0` выключает);
- при привязке пропускает ярчайшие звёзды каталога, если на пластинке они превратились в пятна;
- звёздные величины считает по калибровочной кривой и по всей площади изображения звезды,
  потому что эмульсия насыщается и яркие звёзды растут вширь, а не «вверх»;
- царапины, пыль и надписи остаются в таблице как неопознанные источники (без `cat_mag`).

Команда `simulate` кладёт в набор `plate.tif` — имитацию такой пластинки со всеми этими дефектами.

## Работа с настоящими снимками

Мастер-кадры (если есть калибровочные):

```bash
.venv\Scripts\python -m astropipe masters --bias-frames "bias/*.fits" --dark-frames "dark/*.fits" --flat-frames "flat/*.fits" --out masters
```

Обработка кадра. Нужны приблизительные координаты центра — из заголовка FITS либо вручную:

```bash
.venv\Scripts\python -m astropipe process снимок.fits --ra "05 35 17" --dec "-05 23 28" --scale 1.2 --out out
```

Поиск астероидов в серии кадров одной области:

```bash
.venv\Scripts\python -m astropipe moving "ночь1/*.fits" --out out
```

Сложение серии:

```bash
.venv\Scripts\python -m astropipe stack "ночь1/*.fits" --out stack.fits
```

Полезные ключи: `--scale` (″/пикс, ускоряет и упрощает привязку), `--fwhm` (размер звезды в
пикселях), `--nsigma` (порог обнаружения), `--sip 3` (дисторсия старой оптики),
`--invert/--no-invert` (негатив), `--interval` (секунд между кадрами, если времени нет в заголовке).

## Что получается на выходе

Для каждого кадра в папке `--out`:

- `имя.sources.csv` — таблица звёзд: пиксели, RA/Dec, звёздная величина и ошибка;
- `имя.proc.fits` — очищенный кадр с WCS в заголовке (открывается в DS9, Aladin, ASTAP);
- `имя.preview.png` — картинка: зелёные кружки — звёзды, опознанные по каталогу, жёлтые — остальные;
- `имя.report.json` — число звёзд, точность привязки, масштаб, поворот, предельная величина.

## Ограничения

- «Слепой» привязки нет: нужны координаты центра с точностью порядка поля зрения.
- Тесно слипшиеся звёзды не разделяются (считаются одним источником).
- На пластинках величины самых ярких звёзд (несколько штук на поле) ненадёжны: их слишком мало
  для калибровочной кривой.
- Величины — в полосе Gaia G; цветовая чувствительность эмульсии не учитывается.
- Проверено на синтетических кадрах и на поле, построенном по настоящему каталогу Gaia;
  на реальных снимках с телескопа пока не запускалось.
